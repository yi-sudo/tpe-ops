# dashboard

TPE//OPS 的前端（Vite + React + TypeScript + MapLibre）。只讀 `public/data/`，不直接呼叫外部 API。

```bash
npm install
npm run dev      # http://localhost:5173/
npm run build    # 型別檢查 + 打包到 dist/
npm run lint     # oxlint
```

專案說明、資料來源和完整執行方式見根目錄的 [README.md](../README.md)，程式結構見 [code_structure.md](../code_structure.md)。
